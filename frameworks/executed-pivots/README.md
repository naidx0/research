# Executed Pivots

Rewards an agent's terminal step by what the command actually did, not by whether it matched
the expected keystrokes. Built for NVIDIA's Terminal-Pivot task and served as a NeMo Gym
resources server.

`inspector/index.html` is the Pivot Inspector walkthrough: one self-contained page, no build
step. Open it locally in a browser, or live at https://naidx0.github.io/research/ .

The full project, with its Docker setup and tests, lives in its own public repo:
https://github.com/naidx0/executed-pivots-public
